# Implementation Tasks — Sistem Data WNA

## Cara Menggunakan
Kerjakan berurutan per fase. Sebelum memulai fase, baca `.prd.md`, `.architecture.md`, `.database.md`, dan `.gemini.md`. Selesaikan satu fase, jalankan pemeriksaan, laporkan file yang berubah dan hasil test, baru lanjut. Jangan mengklaim selesai bila build/test belum dijalankan.

## Aturan Pelaporan Tiap Fase
Saat menyelesaikan fase, laporkan:
1. Ringkasan implementasi.
2. File penting yang dibuat/diubah.
3. Command test/build yang dijalankan dan hasil sebenarnya.
4. Keputusan/asumsi yang masih perlu konfirmasi.
5. Fase berikutnya yang siap dikerjakan.

Jangan mengerjakan seluruh fase sekaligus dalam satu perubahan besar tanpa checkpoint. Jangan menghapus data, menjalankan migrasi destruktif, atau mengubah konfigurasi lingkungan tanpa menjelaskan dampak dan meminta persetujuan jika berisiko.
